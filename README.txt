AASHLESHA BIRTHDAY WEBSITE — QUICK SETUP

1. Upload index.html to the ROOT of your GitHub repository (main branch).
2. Create a folder named assets in the repository root.
3. Add your two photos with these exact filenames:
   assets/aashlesha-photo-1.jpg
   assets/aashlesha-photo-2.jpg
4. Commit changes. GitHub Pages should be set to Deploy from a branch > main > /(root).

SOUND NOTE:
Mobile browsers block audio autoplay before a user gesture. The birthday melody starts immediately when the visitor taps “Open your gifts 🎁”. This is the reliable browser-friendly behavior.

The gift boxes are interactive and show a playful message when tapped. The melody is an original little tune synthesized in the browser; no separate audio file is required.
