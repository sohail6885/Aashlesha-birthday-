AASHLESHA BIRTHDAY WEBSITE — QUICK START

FILES
- index.html: complete responsive website (HTML, CSS and JavaScript are included in one file)
- assets/: add Aashlesha's AI-created doctor portraits here

ADD HER PORTRAITS
1. Create a folder named "assets" beside index.html.
2. Add your images with these exact filenames:
   - aashlesha-hero.jpg
   - aashlesha-portrait-1.jpg
   - aashlesha-portrait-2.jpg
   - aashlesha-portrait-3.jpg
3. JPG or JPEG is recommended. If your generated files are PNG, either convert them to JPG or update the corresponding filenames in index.html.
4. The site still works without images; it shows elegant placeholders until you add them.

MUSIC
The Play music button creates an original, gentle celebratory melody in the browser using the Web Audio API. It does not need an external audio file and does not autoplay. This avoids broken music links and lets the visitor choose when to play sound.

PREVIEW LOCALLY
Open index.html in a modern browser. For best results, keep the assets folder beside it.

FREE HOSTING OPTION: GITHUB PAGES
1. Sign in or create an account at https://github.com
2. Create a new public repository, e.g. aashlesha-birthday.
3. Upload index.html and the assets folder containing the portrait files.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose "Deploy from a branch", select "main" and "/ (root)", then Save.
6. Wait for the deployment. GitHub will show a public URL, usually https://YOUR-USERNAME.github.io/aashlesha-birthday/
7. Open that URL on your phone and test all buttons before sharing it.

IMPORTANT
- Test the published link on a phone and check the portrait images.
- The countdown targets the next November 2 according to the visitor's local time.
- This is a static website; it does not collect or send any personal data.
